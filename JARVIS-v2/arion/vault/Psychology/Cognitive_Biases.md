# Cognitive Biases & Mental Models

## Mental Models
- **System 1 vs System 2** (Daniel Kahneman — *Thinking, Fast and Slow*)
  - System 1: Fast, automatic, emotional, instinctive
  - System 2: Slow, deliberate, logical, effortful

## Cognitive Biases (180+ documented)
- **Confirmation Bias** — seek info that confirms existing beliefs
- **Dunning-Kruger Effect** — low skill = overconfidence
- **Availability Heuristic** — recent memories feel more true
- **Anchoring** — first info heard becomes reference point
- **Survivorship Bias** — we see winners, not failures
